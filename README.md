# AkylFlow — MVP 🔥

Мобильная платформа микро-когортного обучения для Центральной Азии: подготовка к **ОРТ**, **Кыргызтест B1** и **IELTS**
короткими уроками по 5 минут, с ИИ-тьютором, дискуссиями в когорте и **огоньками**, которые возвращают человека каждый день.

Работает как веб-приложение и как **Telegram Mini App** (тот же билд). Бэкенд не нужен, прогресс хранится в `localStorage`.

## Что есть в MVP

| Функция | Как работает |
|---|---|
| 🔥 **Личный огонёк** (как в Duolingo) | Серия дней подряд продлевается первым уроком за день. Обратный отсчёт «огонёк погаснет через N ч», календарь недели, рекорд серии, анимация при продлении и на рубежах 3/7/14/30/100 дней |
| ❄️ **Заморозка серии** | Если пропустил день, автоматически тратится заморозка и серия сохраняется. Покупается за Social Coins, максимум 3 |
| 💔 **Восстановление серии** | Погасшую серию можно вернуть за 100 🪙 до следующего урока |
| 🔥 **Огоньки с друзьями** (как в TikTok) | Общая серия с каждым другом растёт, **только если вы оба** занимались в этот день. Уровни огня: Искра (1+), Огонь (3+), Пламя (30+), Легенда (100+). Статусы «твоя очередь / ждём друга», кнопка «👉 Пнуть», восстановление погасшего огонька за 60 🪙 |
| 🤝 **Реальные друзья по ссылке** | Персональная ссылка `?ref=<id>`: друг открывает её, и вы появляетесь друг у друга в списке (нужен Supabase, см. ниже) |
| 📊 **Кто сколько занимался** | Рейтинг «я + друзья» за сегодня и за неделю: XP, серия, ✅ занимался ли сегодня |
| 🔥 **Реальный общий огонёк** | Считается по настоящим дням занятий обоих. «👉 Пнуть» отправляет другу напоминание, он видит его на главном экране |
| 🤖 **ИИ-тьютор** | При ошибке не выдаёт ответ, а задаёт наводящий вопрос (сократический метод) |
| 💬 **Дискуссия под уроком** | Обязательный ответ плюс оценка ответа сокурсника, за это начисляются Social Coins |
| 👥 **Когорта #42** | Рейтинг недели, «N человек занимаются сейчас», дедлайн модуля, комната фокуса (Pomodoro 25 мин) |
| 🎯 **Цель дня** | Кольцо прогресса XP |
| 🎁 **Сундук дня** | После выполнения дневной цели открывается сундук со случайной наградой: монеты или редкая заморозка |
| ⚡ **Комбо** | 3 правильных ответа подряд с первой попытки дают бонус XP, а огонёк в уроке разгорается |
| 🏅 **Достижения** | 10 значков: серии, уроки без ошибок, помощь когорте, огоньки с друзьями |
| 📸 **Огонёк в сторис** | Картинка 1080×1920 с огоньком и ссылкой для Telegram, Instagram и TikTok |
| 🔊 **Звуки и вибрация** | Генерируются в браузере через WebAudio, без файлов. Отключаются в профиле |
| 📱 **PWA** | Ставится на главный экран Android как приложение |
| 🎓 **3 трека** | ОРТ (аналогии, проценты, дополнение предложений), Кыргызтест B1 (лексика, мн. число, знакомство), IELTS (linking words, Speaking, Present Perfect) |

### Для демо на питче
- На стартовом экране есть кнопка **«Открыть с демо-данными»**: серия 13 дней, огоньки с друзьями 47/12/3, один погасший огонёк.
- В **Профиле** есть кнопка **«⏭ Симулировать следующий день»**: видно, как тратится заморозка и гаснут огоньки с друзьями.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `dist/`). Деплой на GitHub Pages идёт автоматически через `.github/workflows/pages.yml` при пуше в `main`.

### Подключение сервера (реальные друзья)
1. Создать бесплатный проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query**: вставить содержимое [`supabase.sql`](supabase.sql) и нажать **Run**.
3. **Project Settings → API**: скопировать *Project URL* и *anon public key* в `src/config.ts`
   (или в переменные `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`).

Без этих ключей приложение работает офлайн, с демо-друзьями.

### Как подключить к Telegram как Mini App
1. Создать бота у [@BotFather](https://t.me/BotFather) → `/newapp` (или `/setmenubutton`).
2. Указать URL GitHub Pages (`https://<user>.github.io/<repo>/`).
3. Приложение само подхватит имя пользователя Telegram, тему и вибро-отклик.

## Структура
```
src/
  content.ts  — уроки, вопросы, подсказки тьютора
  store.ts    — логика огоньков: серия, заморозки, огоньки с друзьями, localStorage
  social.ts   — синхронизация с Supabase: профиль, друзья по ссылке, пинки, общий огонёк
  config.ts   — адрес и anon-ключ Supabase
  Lesson.tsx  — экран урока (вопросы → подсказка ИИ → дискуссия → ревью)
  App.tsx     — экраны: Учёба, Огоньки, Когорта, Профиль, празднование, сундук
  ui.tsx      — SVG-огонёк, конфетти, звуки
  share.ts    — картинка «мой огонёк» для сторис
```

## Ограничения MVP и следующие шаги
- **Когорта пока симулирована**, а друзья настоящие (через Supabase). Вход анонимный (ID на устройстве): с другого телефона это будет новый профиль. Следующий шаг: вход через Telegram и строгие RLS-политики.
- **Напоминания:** уведомление через Telegram Bot API за 3 часа до полуночи, если огонёк не продлён, и «пинок» как реальное сообщение другу.
- **ИИ-тьютор:** сейчас подсказки заранее написаны. Дальше: LLM + Whisper для голоса, память ошибок ученика.
- Адаптивная диагностика (IRT), оплата (Элкарт / Mbank), B2B/B2G-панель.
